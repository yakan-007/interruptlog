INTERRUPTLOG

プライバシーポリシー

最終更新日: 2026年7月4日

InterruptLog Web 版は、個人の作業時間、割り込み、休憩を記録するローカル完結型のアプリです。 入力したデータは利用中のブラウザ内に保存され、開発者のサーバーへ送信されません。

保存される情報

アプリは、次の情報をブラウザの localStorage に保存します。

  • タスク名、メモ、カテゴリ、予定時間、期限
  • 作業、割り込み、休憩の開始時刻、終了時刻、メモ
  • よく使う入力候補、表示設定、日報プロフィール

外部送信について

InterruptLog Web 版は、アカウント、クラウド同期、アクセス解析、広告配信を行いません。 入力データを外部サーバーへ自動送信する機能はありません。

バックアップと復元

JSON バックアップを書き出した場合、保存先や共有先の管理は利用者自身の責任となります。 JSON インポートを行うと、このブラウザ内のデータはバックアップ内容で置き換えられます。

データの削除

設定画面の「全データを削除」またはブラウザのサイトデータ削除により、保存されたデータを削除できます。 ブラウザデータを削除すると、バックアップしていない記録は復元できません。

外部リンク

フィードバック用の GitHub など外部サイトを開いた場合、その外部サイトのプライバシーポリシーが適用されます。
